# Simple Calculator

## 📌 Project Description

The **Simple Calculator** is a beginner-friendly Python project that performs basic arithmetic operations.

The program asks the user to enter two numbers and select an operation. It then performs the selected calculation and displays the result.

## 🎯 Objective

The objective of this project is to learn basic Python programming concepts by creating a simple calculator.

## ✨ Features

The calculator supports:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Division-by-zero handling
* User input

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Interface:** Command Line / Terminal

## 💻 How to Run

### Step 1: Install Python

Install Python on your computer.

### Step 2: Create a Project Folder

Create a folder named:

```text
Simple-Calculator
```

### Step 3: Create Python File

Inside the folder, create:

```text
calculator.py
```

### Step 4: Add the Code

Copy the calculator Python code into `calculator.py`.

### Step 5: Run the Program

Open the terminal in the project folder and run:

```bash
python calculator.py
```
